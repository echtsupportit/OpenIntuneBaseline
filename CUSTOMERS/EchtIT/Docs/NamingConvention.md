# Naming Convention

Format:

<CustomerCode> - <Original OIB Policy Name>

Examples:

EIT - Win - OIB - SC - Device Security - D - Script File Associations - v3.4
TC01 - Win - OIB - SC - Device Security - D - Script File Associations - v3.4
TC02 - Win - OIB - SC - Device Security - D - Script File Associations - v3.4

Rules:

- Preserve the original OIB policy name after the customer prefix.
- Preserve all OIBID values in policy descriptions.
- Do not rename OIBID tokens.
- Do not remove policy descriptions.
- Do not manually edit generated output unless troubleshooting.
