\# Intune Naming Convention



Format:



<OrgPrefix> - <Source> - <Platform> - <PolicyType> - <Scope> - <Purpose> - <Version>



Examples:



EIT - OIB - Win - SC - D - Defender Antivirus - v3.8

EIT - OIB - Win - ES - D - Firewall - v3.8

EIT - Custom - Win - SC - U - OneDrive Known Folder Move



Legend:



EIT     = organization prefix

OIB     = OpenIntuneBaseline

Custom  = internally created policy

Win     = Windows

SC      = Settings Catalog

ES      = Endpoint Security

D       = Device assignment

U       = User assignment
